Guia completa de Custom Program

Pagina independiente de /custom-program para documentar toda la sintaxis legacy y la nueva secuencia PROGRAM sin romper compatibilidad.

1) Campos y operadores

Fuentes disponibles

  • REL1..REL4: salidas/reles.
  • IN1..IN4: entradas digitales fisicas.
  • VIN1..VIN4: entradas virtuales.
  • TEMP1..TEMP4: temperatura.
  • HUM1..HUM2: humedad.

Comparadores y comentarios

  • Operadores: == != > >= < <=.
  • Comentarios por linea: // texto.
  • Comentarios inline: # texto.
  • No soporta expresiones libres + - * / () ELSE.

2) Comandos legacy (compatibles)

SET

Fija un rele.

SET REL1 ON
SET REL2 OFF

BLINK

Parpadeo continuo.

BLINK REL1 500 500

TIMER

Ciclo ON/OFF por tiempos.

TIMER REL2 15000 120000

ONBOOT

Pulso unico tras arranque.

ONBOOT REL1 10000 2000
ONBOOT REL2 12000 2000
ONBOOT REL3 14000 2000

ONCHANGE

Accion por cambio de entrada.

ONCHANGE IN1 TOGGLE REL1

PULSE

Serie de pulsos sobre rele.

PULSE IN2 REL2 1000 2 300

THERMOSTAT

Control con histeresis.

THERMOSTAT REL1 TEMP1 4.0 0.8 COOL

IF / IFALL / IFANY

Condiciones simples o dobles.

IF TEMP1 >= 8 THEN REL4 ON
IFALL TEMP1 > 30 HUM1 > 70 THEN REL2 ON
IFANY IN1 == ON IN2 == ON THEN REL2 OFF

3) Secuencia PROGRAM por pasos

Sintaxis visual recomendada en formato clave=valor. El motor es no bloqueante (millis), con reserva de reles y prioridad de seguridad.

Inicio y fin

PROGRAM NAME=MARMITA_COOL
START IN=IN1
...
END

SET y STEP

SET REL=REL1 STATE=OFF
STEP REL=REL1 STATE=ON TIME=5000
STEP REL=REL1 STATE=OFF

WAIT y WAITUNTIL

WAIT TIME=300000
WAITUNTIL TEMP=TEMP1 OP=<= VALUE=10.0 STABLE=60000 MAX=3600000

LOOP

LOOP MAX=8 UNTIL=TEMP1<=40.0 STABLE=30000
...
ENDLOOP

SAFETY

SAFETY IN=IN4 ACTION=ALL_OFF
SAFETY VIN=VIN2 ACTION=ALL_OFF

Limites clave

  • Maximo 1 PROGRAM.
  • Maximo 1 LOOP, sin anidado.
  • Maximo 24 pasos ejecutables.
  • Tiempos 50..86400000 ms.
  • Reles usados quedan reservados mientras corre la secuencia.

4) Entradas virtuales VIN

Arranque por VIN

PROGRAM NAME=VIN_START
START VIN=VIN1
STEP REL=REL1 STATE=ON TIME=1000
END

El arranque usa flanco ascendente OFF -> ON, igual que IN fisica.

Parada virtual opcional

SAFETY VIN=VIN2 ACTION=ALL_OFF

Sirve como paro remoto desde UI/cloud. Para emergencia real, usa tambien una entrada fisica cableada con SAFETY IN=INx.
