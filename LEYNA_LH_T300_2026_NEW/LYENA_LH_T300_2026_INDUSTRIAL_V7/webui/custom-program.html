Guia completa Volver a /app

Legacy (compatible): SET, BLINK, TIMER, ONBOOT, ONCHANGE, PULSE, THERMOSTAT, IF, IFALL, IFANY.
Secuencia PROGRAM (visual): START IN=IN1 o START VIN=VIN1, STEP REL=REL1 STATE=ON TIME=5000, WAIT TIME=2000, WAITUNTIL ..., LOOP COUNT=2 o LOOP MAX=8 UNTIL=..., SAFETY ... y END.
Comparadores: == != > >= < <=.

Ejemplo visual rapido

PROGRAM NAME=ARRANQUE_RAPIDO START VIN=VIN1 STEP REL=REL1 STATE=ON TIME=5000 WAIT TIME=1000 STEP REL=REL1 STATE=OFF SAFETY IN=IN4 ACTION=ALL_OFF END

API y cloud para VIN

  • POST /api/v1/control con {"pulseVirtualInput":"VIN1"}.
  • En cloud: usar desiredState.pulseVirtualInput para pulsos.
  • GET /api/v1/state expone virtualInputs y estado de secuencia.
