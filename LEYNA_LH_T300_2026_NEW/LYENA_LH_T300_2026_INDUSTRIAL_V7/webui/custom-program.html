Programa Custom (WORK_CUSTOM)

Editor seguro de reglas online para relays. El parser valida sintaxis y ejecuta en ciclos no bloqueantes.

--
Volver a /app

Comandos validos: SET RELn ON|OFF BLINK RELn onMs [offMs] TIMER RELn onMs offMs ONBOOT RELn delayMs onMs ONCHANGE INn TOGGLE RELm PULSE INn RELm onMs count [gapMs] THERMOSTAT RELn TEMPm setpoint diff [AUTO|COOL|HEAT] IF TEMPn op valor THEN RELm ON|OFF IF HUMn op valor THEN RELm ON|OFF IF INn op ON|OFF THEN RELm ON|OFF IFALL src1 op v1 src2 op v2 THEN RELm ON|OFF IFANY src1 op v1 src2 op v2 THEN RELm ON|OFF Operadores: == != > >= < <=

Referencia completa

Campos del script

  • REL1..REL4: salidas (reles) que puedes activar.
  • IN1..IN4: entradas digitales.
  • TEMP1..TEMP4: sondas de temperatura.
  • HUM1..HUM2: sondas de humedad.
  • Maximo de reglas: 24.

Sintaxis disponible

  • SET RELn ON|OFF
  • BLINK RELn onMs [offMs] (50..3600000 ms)
  • TIMER RELn onMs offMs (50..3600000 ms)
  • ONBOOT RELn delayMs onMs (pulso unico tras arranque, 50..3600000 ms)
  • ONCHANGE INn TOGGLE RELm
  • PULSE INn RELm onMs count [gapMs] (count 1..20)
  • THERMOSTAT RELn TEMPm setpoint diff [AUTO|COOL|HEAT]
  • IF TEMPn op valor THEN RELm ON|OFF
  • IF HUMn op valor THEN RELm ON|OFF
  • IF INn op ON|OFF THEN RELm ON|OFF
  • IFALL src1 op v1 src2 op v2 THEN RELm ON|OFF
  • IFANY src1 op v1 src2 op v2 THEN RELm ON|OFF

Condiciones y matematica

  • Comparadores: == != > >= < <=
  • Soporta histeresis con THERMOSTAT usando setpoint y diff.
  • Soporta compuertas logicas de 2 condiciones con IFALL (AND) y IFANY (OR).
  • No soporta expresiones libres: + - * / () ELSE.
  • Comentarios: linea con // o inline con #.

API local para actuar

  • GET /api/v1/config
  • POST /api/v1/config para guardar config completa.
  • POST /api/v1/control para cambios rapidos de control.
  • GET /api/v1/state para validacion del parser.
  • Estado parser: customProgramValid, customProgramRuleCount, customProgramError.

Campos clave (control local)

  • workMode (0..4)
  • customProgram (texto del programa)
  • setpoint, setpoint2
  • manualRelays (array bool)
  • relay1..relay4 (bool)

Campos cloud desiredState

  • workMode, customProgram, power, mode, fan
  • setpoint, setpoint2, differentialX10
  • highAlarmX10, lowAlarmX10, tempAlarmDelayMin
  • controlPeriodMs, defrostIntervalMin, defrostDurationMin, defrostStopX10
  • stopRelay1OnDefrost, stopRelay2OnDefrost, relay2Mode, relay3Mode
  • relays objeto: {"REL1":true,"REL2":false,...}
